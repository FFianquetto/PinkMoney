PINK MONEY - RESUMEN DE ARQUITECTURA
=====================================
App nativa iOS 26+ (iPhone y iPad) de finanzas para estudiantes.
Hoy funciona 100% local. Firebase esta construido pero apagado.


1. TECNOLOGIAS
--------------
- Swift 5.9 + SwiftUI (interfaz)
- SwiftData (base local: gastos y perfil)
- Swift Charts (dona y barras)
- UserNotifications (aviso "El Cerdo avisa del limite" al 90% y 100%)
- Network / NWPathMonitor (deteccion de internet)
- Keychain + CryptoKit SHA256 (sesion y contrasenas locales)
- Firebase Auth y Firestore por REST con URLSession (apagado)
- Sin dependencias de terceros


2. ARQUITECTURA
---------------
Patron: MVVM + Repository.

  Vistas (SwiftUI)
     |
  ViewModels: LedgerStore, ExpenseViewModel, DashboardViewModel
     |
  Ledger = unica fuente de verdad de los numeros
     |
  Repositorios (SwiftData) --> Base local

Piezas clave:
- Ledger: calcula gastado del mes, hoy, disponible, % y limite (>= 90%),
  agrupacion por dia, categorias e historico mes/anio.
- LedgerStore: recalcula el Ledger al instante tras cada alta, baja o
  cambio de presupuesto (por eso el contador se actualiza al guardar).
- AuthService: sesion local, perfil y presupuesto.
- SyncManager: cola con Firestore (isSynced). Apagada.
- NotificationService: avisos de limite, 1 vez por nivel y por mes.

Banderas (PinkTheme):
- requiresLogin = false      -> abre directo al menu, sin login
- cloudSyncEnabled = false   -> todo local, sin Firebase
- defaultBudget = 8,000


3. FLUJO
--------
Arranque:  Splash -> sesion local -> Menu principal

Guardar gasto:
  "+" -> escribir monto (comas en vivo) -> Guardar
  -> se guarda en SwiftData -> se recalcula el contador
  -> aviso de limite si aplica -> regresa a Inicio (arriba) -> cierra modal

Borrar gasto:
  Deslizar la fila a la izquierda y soltar = se borra directo
  (necesita pasar 40% del ancho de la fila, o deslizar rapido).
  Si se suelta antes, la fila regresa.

Historico (Radiografia):
  Selector Mes / Anio + flechas para moverse de periodo.
  Muestra total, movimientos, promedio, dona, mayor fuga y desglose.
  En Anio: barras por mes y lista mes por mes (tocar un mes lo abre).

Navegacion (barra inferior flotante):
  Inicio | Movimientos | [ + ] | Radiografia | Perfil


4. PANTALLAS
------------
- Splash ............. entrada animada con el Cerdo
- Inicio ............. saludo, presupuesto, alertas, ultimos movimientos

7. DATOS
--------
- Base SwiftData "PinkMoney" en el iPhone (sin iCloud).
- Modelos: Expense (monto, categoria, fecha, nota, isSynced)
           UserProfile (correo, presupuesto, nombre, escuela)
- Si la base no abre, se aparta como respaldo; nunca se borra.
- Nube (apagada): users/{uid} y users/{uid}/expenses/{id},
  con reglas para que cada usuario solo vea lo suyo.
